## Post-review robustness fix

After the first formal run exposed a repeated Bundle Refine hash mismatch, the
implementation was inspected. The parser was correct, but the prompt required
the Manager to calculate long-description SHA-256 values itself. The Manager
now receives exact current child-description hashes to copy verbatim via
`bundle_refine_prompt_subtree`; strict parser validation is unchanged. The
pause artifact also preserves `BundleManagerFailure.to_dict()` including the
raw response for future diagnosis. The focused prompt-hash test passes.
