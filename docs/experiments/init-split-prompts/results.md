## 4. 耗时与重要结论

| 项目 | 英文模板 v1 | 本次偏好 v2 |
|---|---:|---:|
| init split | 28.00 分钟 | 40.94 分钟 |
| 正式 VLRB 外评 | 145.85 分钟 | 152.42 分钟 |
| 两阶段合计 | 173.85 分钟 | 193.36 分钟 |
| Manager 逻辑调用 / 尝试 | 148 / 149 | 148 / 180 |

本次额外尝试包括 31 次服务端 503 和 1 次解析失败；初始化耗时差不能全部归因于提示词。复算时各版本正式预测均无未解决技术失败。

1. **综合未见样本改善。**v2 在 1147 与去近重复 1146 上均优于旧 S0 和 v1；Strict 与 Covered 同时提高，收益并非靠大量弃权获得。
2. **收益不均匀。**General 改善最大，主要来自 WildVision；Hallucination 的净收益主要来自 RLAIF-V。POVid、RLHF-V 相对 v1 略降，Reasoning 基本持平。
3. **幻觉主切片尚无显著提升证据。**648 上增量区间包含零，不能把单次正向变化表述为稳定显著提升；当前统计也不覆盖 Rubric 生成与推理的重复运行波动。
4. **准则更强调比较权衡，但仍有边界与重叠。**新增主要答案优先、错误累积、确定性与清晰度匹配等指导；部分根重复使用幻觉严重度，视觉扎根的部分子准则放宽了原根对外部知识的限制。暂保留为后续演化观察项，不认定冗余已被解决。
