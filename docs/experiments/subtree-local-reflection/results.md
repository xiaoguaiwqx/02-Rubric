# 结构化 Rubric：最终实验结果

最终方案为**偏好归纳五根 + 初始子准则 + 五轮子树局部演化 + Global Arbiter**。在 VL-RewardBench 上，全量 Strict ACC 为 **75.78%（945/1247）**，未参与演化的 1147 条为 **75.07%（861/1147）**，幻觉留出集为 **84.10%（545/648）**。

本页对应最终汇报表，仅展示当前结果及必要对照。方法见[主要框架图](../../../assets/framework.png)，运行入口与配置见仓库 [README](../../../README.md)。

## 实验设置与计分

- **数据**：从 VL-RewardBench 冻结划分 100 条幻觉案例作为演化集，seed=11；其余 1147 条不参与演化，其中幻觉留出集为 648 条。五条 root 生成预热样例来自演化集。
- **模型**：Worker 为 Qwen3-VL-8B-Instruct，temperature=0.5、max_tokens=2048；Manager 为 Qwen3.5-27B，temperature=0.2、关闭 thinking。
- **最终演化配置**：最多五轮，以局部 Strict ACC 严格提升为接受条件；Preserve5 为候选修订提供最多五条当前判断正确的案例，preservation_seed=42。root 固定，仅更新整组 children。
- **正式计分**：子树判断与 Global Arbiter 使用同一 A/B 展示顺序，每次结果还原到原始回答；K=3 至少两票一致，否则弃权。**Strict ACC = 正确数 / 全部样例数，弃权计错**。下面各切片均使用该正式 K=3 口径，包括演化集 100 条。

## 主要观察

1. **最终方案在表中达到最高系统准确率。** 相比人工预设五根的五轮结果，全量增加 25 条正确（+2.00 个百分点），未参与演化集增加 25 条（+2.18 个百分点），幻觉留出集增加 11 条（+1.70 个百分点）。这些是完整方案间的观察差异，不能单独归因于 root 生成方式。
2. **偏好归纳五根的后续流程带来进一步改善。** R0 → S0 → Final 的全量正确数为 925 → 933 → 945；未参与演化集为 841 → 851 → 861，对应 73.32% → 74.19% → 75.07%。R0 → Final 全量净增 20 条，未参与演化集同样净增 20 条。
3. **幻觉留出集的演化收益较小。** R0 → S0 → Final 为 541 → 544 → 545；五轮演化相对 S0 仅净增 1 条。S0 → Final 在 General、Hallucination、Reasoning 分别净增 4、3、5 条。

Final 全量覆盖 1232/1247，弃权 15 条。官方 OverallAcc 为 76.70%、MacroAcc 为 70.27%，它们排除弃权，与主表的 Strict ACC 分开记录。
